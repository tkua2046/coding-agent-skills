# 0.1.0 source baseline: original evidence

These archives preserve original worker/grader traces, inputs, outputs, failures, independent reviews and packages. This is evidence publication, not full release qualification. Earlier evidence remains in the parent history and tree.

Download an archive and check its SHA-256 against [SHA256SUMS](SHA256SUMS). Extract to an empty directory, preserving archive paths. Nested ZIPs are retained verbatim. Adjacent [archive-index.json](archive-index.json) maps each download to the original local path used by source documentation. Follow each campaign's results.md or START_HERE.md; referenced raw run directories are included.

The r3 portable ZIP has the same 39 runtime files as this baseline; its bundled documentation is historical. Use the source branch for current documentation.

Archive integrity and limited credential-pattern checks are recorded alongside. No credential-pattern matches were found; this is not exhaustive certification.
