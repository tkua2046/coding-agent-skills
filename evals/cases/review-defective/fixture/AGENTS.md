# Working here

This local stock export tool uses only the Python standard library.
Preserve the CLI and data contract in normal maintenance. Tests use unittest;
quality.ini owns the qa/ location and custom check_*.py discovery pattern.
Contributor commands are in DEVNOTES. Feature requirements and decisions live
under docs/, and review reports under docs/reviews/.

The current task is a single authorized document review. Read the existing code,
requirements, design and plan, then write findings only. No product or plan edits,
implementation, commits, tags, pushes, external actions or extra approval rounds.
Static inspection does not establish future runtime success or human acceptance.
