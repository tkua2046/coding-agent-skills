3. **Which behavior is authoritative for the conflicting legacy case?** Must existing calls continue returning `"SS"` for `"ß"`, or is the test's `"ß"` expectation a required correction? If correction is intended, is it in this feature's scope? Preserving observed behavior and satisfying this assertion cannot both hold for the same call.
