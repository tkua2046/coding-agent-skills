1. The investigation examined repeated catalog loading in order reports. `summarize` reloads JSON and rebuilds the SKU map for every order. Local scratch comparisons showed that loading once per nonempty batch substantially reduced runtime. For 1,000 orders and 1,000 catalog rows, loads dropped from 1,000 to one, and median runtime dropped from 322 ms to 0.471 ms. A separate profile attributed about 91% of existing runtime to `load_catalog`, establishing repeated loading as the dominant cost in the local experiment.
